# ФізикаPRO — сайт вчителя фізики та математики

Статичний сайт: звичайні HTML-файли, стилі, картинки й шрифти. Не потребує сервера, бази даних чи збірки. Його можна розмістити на GitHub Pages, а згодом перенести на будь-який хостинг або домен, просто скопіювавши папку.

## Сторінки
| Файл | Сторінка |
|---|---|
| `index.html` | Головна |
| `pro-mene.html` | Про мене |
| `fizyka.html` | Фізика (теми 7–11 класів) |
| `matematyka.html` | Математика (теми 5–11 класів) |
| `materialy.html` | Матеріали з фільтром |
| `zaniattia.html` | Формати занять, ціни, запитання |
| `kontakty.html` | Контакти й форма запису |
| `404.html` | Сторінка «не знайдено» |

## Що замінити своїми даними (повний список)
| Файл | Що замінити |
|---|---|
| `index.html` | `[Ваше ім'я та прізвище]` у блоці `<script type="application/ld+json">` (для пошукових систем) |
| `pro-mene.html` | ім'я, текст про себе, `[__]` років досвіду й кількість учнів, освіта, кваліфікація, досягнення; фото (див. нижче) |
| `zaniattia.html` | ціни `[___] грн` (3 місця); **у згорнутих відповідях FAQ:** платформа для онлайн-занять і спосіб оплати |
| `kontakty.html` | Telegram `your_username` (2 місця); Viber `%2B380000000000` і `+380 00 000 00 00`; телефон `tel:+380000000000` і `+380 00 000 00 00`; e-mail `your@email.com` (2 місця, зокрема **невидимий** `data-email="..."` у формі); `[Місто]`; у тексті про персональні дані `[ПІБ / ФОП]`, `[e-mail]` |

**Самоперевірка.** Якщо маєте комп'ютер із терміналом, команда нижче покаже все, що ще не замінено:
```
grep -rn "\[\|your_\|000 00\|380000000000\|your@" *.html
```

**Фото.** Покладіть файл у `assets/img/` (наприклад, `photo.jpg`). У `pro-mene.html`, у блоці `<div class="photo">`, замініть `assets/img/emblem.png` на `assets/img/photo.jpg`, приберіть клас `ph` і впишіть в `alt=""` своє ім'я.
⚠️ **Перед завантаженням видаліть з фото метадані.** Фото з телефона часто містить GPS-координати, тобто місце зйомки. Як видалити: Windows — «Властивості → Подробиці → Видалити властивості й особисті дані»; Mac — відкрити в «Перегляді» й експортувати; або командою `exiftool -all= photo.jpg`.

Кольори змінюються на початку файлу `assets/css/style.css`.

## Публікація на GitHub Pages
1. Увімкніть двофакторну автентифікацію в акаунті GitHub (Settings → Password and authentication).
2. Створіть новий репозиторій, наприклад `fizykapro`, з типом **Public**.
3. Натисніть **Add file → Upload files** і перетягніть **вміст** цієї папки (не саму папку), разом із папкою `assets`. Файл `.nojekyll` бажано теж завантажити, але якщо він загубився (на Mac він прихований), сайт усе одно працюватиме. Натисніть **Commit changes**.
4. Відкрийте **Settings → Pages**. У розділі *Build and deployment* оберіть **Deploy from a branch**, гілку `main`, папку `/ (root)` і натисніть **Save**.
5. За 1–2 хвилини сайт з'явиться за адресою `https://ВАШ_ЛОГІН.github.io/fizykapro/`.

Сторінка 404 сама визначає адресу сайту, тому коректно відкривається й на вкладених адресах. Скрипт для цього стоїть на початку `404.html` і має свій хеш у Content-Security-Policy. Якщо зміните текст скрипту, перерахуйте хеш:
```
python3 -c "import hashlib,base64,sys;print('sha256-'+base64.b64encode(hashlib.sha256(sys.argv[1].encode()).digest()).decode())" '<вміст script>'
```

## Перехід на власний домен

### Безпека домену (зробіть насамперед)
1. **Підтвердьте домен** у GitHub: аватар → **Settings → Pages → Add a domain**. Додайте у DNS TXT-запис `_github-pages-challenge-ВАШ_ЛОГІН` зі значенням, яке покаже GitHub, і натисніть **Verify**. Після цього ніхто інший не зможе прив'язати ваш домен до свого сайту.
2. Порядок важливий: **спочатку** домен у налаштуваннях GitHub, **потім** DNS. Не використовуйте wildcard-записи (`*.домен`).
3. Увімкніть двофакторну автентифікацію у реєстратора домену.

### Варіант A: власний домен, хостинг на GitHub
1. У налаштуваннях репозиторію відкрийте **Settings → Pages → Custom domain**, впишіть домен і збережіть. GitHub створить файл `CNAME`.
2. У DNS реєстратора додайте записи:
   - для `www`: CNAME на `ВАШ_ЛОГІН.github.io`;
   - для кореневого домену: A-записи `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153` і AAAA-записи `2606:50c0:8000::153`, `2606:50c0:8001::153`, `2606:50c0:8002::153`, `2606:50c0:8003::153`.
3. Коли DNS запрацює, увімкніть **Enforce HTTPS**. Галочка може бути неактивною до 24 годин, поки GitHub випускає сертифікат. Стара адреса `github.io` автоматично перенаправлятиме на домен.

### Варіант B: інший хостинг
Скачайте репозиторій (**Code → Download ZIP**) і завантажте вміст на новий хостинг. Уся інформація зберігається у файлах, тож нічого не втрачається.
⚠️ **Спочатку переведіть DNS на новий хостинг**, і лише потім видаляйте `CNAME`, репозиторій чи налаштування Pages. DNS, що вказує на GitHub без активного сайту, дозволяє стороннім перехопити домен.

### Чекліст після переїзду на домен
Ці речі залежать від адреси сайту, тому їх додають, коли домен уже відомий:
- [ ] **Картинка для соцмереж.** У `<head>` кожної сторінки додайте `<meta property="og:image" content="https://ВАШ-ДОМЕН/assets/img/og.jpg">` і `<meta property="og:url" content="https://ВАШ-ДОМЕН/сторінка.html">`. Картинку зробіть 1200×630 px. Telegram, Viber і Facebook розуміють лише повну адресу.
- [ ] **Canonical.** На кожній сторінці додайте `<link rel="canonical" href="https://ВАШ-ДОМЕН/сторінка.html">`.
- [ ] **robots.txt** у корені:
  ```
  User-agent: *
  Allow: /
  Sitemap: https://ВАШ-ДОМЕН/sitemap.xml
  ```
- [ ] **sitemap.xml** з повними адресами всіх 7 сторінок.
- [ ] Зареєструйте сайт у Google Search Console.

## Технічні деталі
- **Шрифт.** Montserrat зберігається в `assets/fonts/` (ліцензія SIL Open Font License, див. `OFL-LICENSE.txt`). Сайт не звертається до сторонніх сервісів.
- **Захист.** На кожній сторінці є Content-Security-Policy і Referrer-Policy. Якщо підключатимете аналітику чи сервіс форм, ці правила доведеться розширити.
- **Форма запису.** Вона відкриває лист у поштовій програмі відвідувача. Сайт нічого не збирає й не зберігає, а під формою є повідомлення про обробку персональних даних.
- **Зображення.** Сайт використовує WebP із запасним PNG.
- **Доступність.** Сайт адаптований під телефони, планшети й комп'ютери, ним можна керувати з клавіатури, а в коді є розмітка для екранних зчитувачів.
